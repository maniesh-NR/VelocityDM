## Conditions → plan mapping

All conditions are folded into the revised spec
`docs/SPECS/S6-DASH-MPD.md` (committed in the same activation commit):

1. `Error::Dash(String)` pinned (FALS #6 / REQ #7 / INT #6 / REL #1);
   mirror list completed (engine/mod.rs + error.rs, both trees).
2. Selection semantics = `choose_variant` exactly (nearest, ties to
   earlier position, junk error) (FALS #1 / REQ #2).
3. Duration math: count = ceil(period-length × timescale ÷ duration);
   period-length precedence; $Time$ in timescale units; PTO ≠ 0
   loud-fail; @t/@r rules incl. @r=-1; overflow-checked parsing;
   100,000-segment cap; duration=0/timescale=0 errors (FALS #2/#9 /
   REQ #1 / ATKR #2).
4. SegmentTemplate inheritance at three levels, child-wins; init
   template identifier restriction; absent-initialization legal;
   neither-duration-nor-timeline loud-fail (FALS #3 / REQ #5).
5. SIDX: first_offset + version handling, 100k reference cap,
   checked_add, byte-accurate anchoring (FALS #8 / ATKR #3 / REL nits).
6. XML hardening: DOCTYPE literal, no ENTITY expansion, iterative
   depth-capped skipper, char::from_u32, 4 KiB attrs (ATKR #1/#6).
7. Detection: ≤1 KiB internal probe head-sniff, fail-open; dispatch
   placement pinned before the size/range gate; content_type fallback
   on the 405 path (ATKR #7 / INT #1/#7 / REQ #3).
8. Naming: .mpd-strip + .mp4 forcing mirrors the .ts pattern; explicit
   filename semantics honest (ATKR #7 / REQ #4 / INT #2).
9. Events/progress: throttled snapshot path; e2e asserts final bytes +
   done==size + ≥1 intermediate done (ATKR #8 / FALS #7 / REQ #9).
10. Single-connection sequential declared as a deliberate deviation;
    scheme+host+port reuse key in the new code (FALS #10 / ATKR #5).
11. Release/rollback + close-out chain + MSRV witness + banned APIs +
    win7 test-shape source (REL #2-4 / INT #3-5).
12. Deferred sub-stages section (audio muxing, text tracks, live,
    multi-period, multi-rep, parallelization, PTO, credential-header
    policy) (REQ #6 / FALS #12).
